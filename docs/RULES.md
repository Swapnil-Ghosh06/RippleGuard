# RippleGuard — Hackathon Rules (Condensed)
### Quick-reference checklist distilled from the official Manipal Hackathon 2026 Round 1 Rulebook. When in doubt, the PDF rulebook is authoritative — this file exists so the team doesn't have to re-read all 20 pages under deadline pressure.

---

| Date | Event |

| 3 Oct | RSVP by shortlisted teams |

| 14–16 Oct | Round 2 — onsite at MIT Manipal, 36 hours |

## 2. Round 1 Submission Checklist (what we're building toward now)
- [ ] **Presentation:** official template ONLY, exported as **PDF** (not .ppt/.pptx) — file name `TeamID_TeamName_CS0202`
- [ ] **No institute name, logo, or any hint of which college** — anywhere in the deck, video, or GitHub repo
- [ ] **Video:** max 2 minutes (3 minutes if it includes a prototype demo), every registered team member visible, min 640×480, hosted on Google Drive ("Anyone with the link") or YouTube (Unlisted/Public), English only
- [ ] **Prototype (optional but scored):** GitHub repo must be **publicly accessible** for the entire evaluation window — private/inaccessible = forfeits all prototype bonus points
- [ ] Verify every link (video + repo) in an **incognito window** before the deadline
- [ ] All submissions go through the official portal only — no email/messaging apps
- [ ] Team may resubmit until the deadline; latest version before deadline is final — no extensions

## 3. Tier 1 — Instant Disqualification
- Missing the presentation or video
- Broken/restricted video URL (access-request-gated Drive links, private YouTube)
- Solution doesn't match the selected Problem Statement ID
- Plagiarism or recycled prior work
- Offensive/inappropriate content anywhere, including the GitHub repo
- Unauthorized cooperation with another competing team

## 4. Tier 2 — Point Deduction (still evaluated)
- Wrong file naming convention
- Accidental institute-identity disclosure in submitted media
- Minor deviation from the official template
- Video over the time limit (2 min standard / 3 min with prototype)

## 5. AI Usage Policy
No cap on AI usage, no disclosure required. What can't come from AI: the idea itself, the architecture judgment calls, the reasoning for why the solution matters. Every team member must be able to explain and defend any part of the submission in their own words — unexamined AI output scores lower under Innovation/Implementation Quality (8.1), but is **not** a disqualification trigger.

## 6. Judging Criteria Weight (know what you're optimizing for)
| Criterion | What it measures |
|---|---|
| 8.1 Innovation Beyond Requirements | Feature novelty + implementation quality of features beyond the problem statement — this is why CREATIVE_IDEAS.md exists |
| 8.2 Feasibility | Practicality, implementation roadmap, inclusivity (npm + PyPI coverage) |
| 8.3 Marketing/Media Strategy | Outreach plan, target audience clarity, real-world applicability |
| 8.4 Monetisation | Revenue model clarity, scalability, sustainability |
| 8.5 Adherence to Format | Did we use the mandatory template + follow video rules |
| 8.6 Prototype Bonus | Functional + publicly accessible prototype = bonus marks on top |

## 7. Eligibility (already satisfied by the team, noted for reference)
B.Tech/B.E./dual-degree students, same institute, teams of 2–5, one team per participant. Round 2 (if shortlisted) requires at least 2 members physically on the MIT Manipal campus for the full 36 hours — accommodation/food provided; ₹349 (+GST for non-MAHE) registration fee applies at that stage, not now.
